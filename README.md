# Roblox Fishing Bot

บอทตกปลาอัตโนมัติ: เหวี่ยงเบ็ด → เล่นมินิเกม (ไล่ตัวขาวให้อยู่ในโซนเขียว) → กด T ค้าง 8 วิเก็บของ → วนใหม่

## ติดตั้ง
```
pip install -r requirements.txt
```

## ใช้งาน
ดับเบิลคลิก `เปิดบอทตกปลา.bat` (หรือ `pythonw gui.py`) — แอปมี 2 แท็บ:

- **บอท**: เริ่ม/หยุด, ตัวนับ, ปรับค่า, หาแถบใหม่
- **ทดสอบ**: วัดว่าระบบจับภาพแม่นแค่ไหน (รอปลากิน / มินิเกม / ปุ่ม T) พร้อมแคปภาพไว้ใน `check/`
  - *ทดสอบอัตโนมัติ*: บอทเล่นเองตามจำนวนรอบ แล้วสรุปผล
  - *ทดสอบแบบเล่นเอง*: ดูจออย่างเดียว ไม่คลิก/ไม่กดปุ่ม

รันแบบไม่มีหน้าต่างก็ได้: `python fishing_bot.py`

| ปุ่ม | ทำอะไร |
|---|---|
| F6 | เปิด/ปิดบอท |
| F8 | ตั้งตำแหน่งแถบเอง (เมาส์ชี้ที่แถบตอนมินิเกมขึ้น) |
| F10 | เซฟภาพหน้าต่างเกมเป็น `debug.png` |
| F7 | ออก |

ค่าที่ปรับได้อยู่บนสุดของ `fishing_bot.py` (`GAIN`, `LEAD`, `CAST_TIMEOUT`, `COLLECT_HOLD` ฯลฯ)

> หมายเหตุ: การใช้ macro/บอทอาจผิดกฎของเกม ใช้ด้วยความเสี่ยงของตัวเอง
