# Roblox Fishing Bot

บอทตกปลาอัตโนมัติสำหรับมินิเกมตกปลาใน Roblox

```
เหวี่ยงเบ็ด → รอปลากิน ──(เกิน 30 วิ)──→ เก็บสาย + เหวี่ยงใหม่
                 ↓
      เล่นมินิเกม (ไล่ตัวขาวให้อยู่ในโซนเขียว) → จบ → รอ 1 วิ
                 ↓
      เห็นปุ่ม T → กด T ค้าง 6.5 วิ (เก็บของ) → วนใหม่
```

- หาหน้าต่าง Roblox เอง (มีหลายจอก็ได้) และหาตำแหน่งแถบมินิเกมเองตอนมินิเกมขึ้นครั้งแรก
- จับภาพได้ทั้งพื้นหลังสว่าง/มืด โซนสีเขียวหรือเหลือง และปรับตามความละเอียดจอ
- กดเริ่ม/หยุดได้ทุกเวลา แม้บอทกำลังกด T ค้างหรือเหวี่ยงเบ็ดอยู่
- มีระบบทดสอบความแม่นยำก่อนใช้จริง และอัปเดตตัวเองจาก GitHub

## ติดตั้ง

ต้องมี [Python 3](https://www.python.org/downloads/) และ [Git](https://git-scm.com/downloads)

```
git clone https://github.com/LAKZTV/roblox-fishing-bot.git
```

แล้วดับเบิลคลิก **`เปิดบอทตกปลา.bat`** — ครั้งแรกจะติดตั้งไลบรารีที่ต้องใช้ให้เอง (1-2 นาที)
ถ้ามีปัญหา หน้าต่างจะบอกสาเหตุ และถ้าแอปเปิดไม่ได้จะมีกล่องข้อความ + บันทึกไว้ใน `error.log`

> ติดตั้งด้วย `git clone` เท่านั้นถึงจะอัปเดตอัตโนมัติได้ (ดาวน์โหลดเป็น ZIP จะอัปเดตเองไม่ได้)

## ใช้งาน

ดับเบิลคลิก **`เปิดบอทตกปลา.bat`** (หรือรัน `pythonw gui.py`) แล้วเปิดเกมไว้แบบไม่ย่อหน้าต่าง

### แท็บ "บอท"
- **เริ่ม / หยุด** — ปุ่มใหญ่ หรือกด `F6`
- **ตัวนับ** — ได้ของ / มินิเกม / เหวี่ยง / พลาด และเวลาที่ทำงาน
- **ตั้งค่า** — ปรับได้ระหว่างทำงาน มีผลทันที (จำไว้ใน `settings.json`)

  | ค่า | ความหมาย |
  |---|---|
  | กด T ค้าง (วิ) | เวลากด T เก็บของ (ค่าเริ่มต้น 6.5) |
  | รอปลากินนานสุด (วิ) | ถ้ามินิเกมไม่ขึ้นภายในเวลานี้ จะเก็บสายแล้วเหวี่ยงใหม่ |
  | กดเหวี่ยงเบ็ด (วิ) | เวลากดเมาส์ตอนเหวี่ยง |
  | ความแรงไล่โซน | มากไป = ตัวขาวแกว่ง, น้อยไป = ตามโซนไม่ทัน |

- **หาแถบใหม่ / ลืมตำแหน่งแถบ** — ใช้เมื่อย้ายหรือเปลี่ยนขนาดหน้าต่างเกม

### แท็บ "ทดสอบ"
เช็คว่าระบบจับภาพเกมของคุณได้แม่นแค่ไหน ก่อนใช้บอทจริง

- **ทดสอบอัตโนมัติ** — บอทเล่นเองตามจำนวนรอบที่ตั้ง แล้วสรุปผล
- **ทดสอบแบบเล่นเอง** — ดูจออย่างเดียว ไม่คลิก/ไม่กดปุ่ม ผู้เล่นตกปลาเอง

วัดผล 3 ช่วง: รอปลากิน (ต้องไม่จับผิด) / มินิเกม (จับตัวขาว+โซน) / ปุ่ม T
แล้วบอกผลรวมพร้อมคำแนะนำ (ดีมาก / ดี / พอใช้ / ควรปรับ)
ภาพพร้อมกรอบสิ่งที่จับได้และ `report.json` เก็บไว้ในโฟลเดอร์ `check/`

### อัปเดตอัตโนมัติ
- เช็คอัปเดตตอนเปิดแอป และทุก 30 นาที
- ถ้าติ๊ก **อัปเดตอัตโนมัติ** (ค่าเริ่มต้น) และบอทไม่ได้ทำงานอยู่ จะอัปเดตแล้วเปิดแอปใหม่เอง
- ถ้าบอททำงานอยู่ จะขึ้นแถบ "มีอัปเดตใหม่ — กดเพื่ออัปเดต" แทน
- กด **เช็คอัปเดต** ที่มุมล่างเพื่อเช็คเองได้

### ปุ่มลัด (กดได้ทุกเวลา)

| ปุ่ม | ทำอะไร |
|---|---|
| F6 | เริ่ม / หยุดบอท |
| F8 | ตั้งตำแหน่งแถบเอง (เมาส์ชี้ที่แถบตอนมินิเกมขึ้น) |
| F10 | เซฟภาพหน้าต่างเกมเป็น `debug.png` |
| F7 | ปิดโปรแกรม |

รันแบบไม่มีหน้าต่างก็ได้: `python fishing_bot.py` (ใช้ปุ่มลัดควบคุม)

## ข้อควรรู้
- บอทใช้เมาส์และคีย์บอร์ดจริง และต้องเห็นภาพเกม — **ย่อหน้าต่างเกมไม่ได้** และระหว่างบอททำงานไม่ควรใช้เมาส์/คีย์บอร์ดทำอย่างอื่น
- ถ้ากด T หรือคลิกแล้วเกมไม่รับ ลองเปิดแอปแบบ Run as administrator
- ค่าละเอียดอื่นๆ อยู่บนสุดของ `fishing_bot.py` (`LEAD`, `COLLECT_RETRIES`, `RECAST_CLICKS` ฯลฯ)

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `gui.py` | แอป (แท็บบอท + ทดสอบ) |
| `fishing_bot.py` | ตัวบอท (จับภาพ + ควบคุม) |
| `checker.py` | ระบบวัดความแม่นยำ |
| `updater.py` | อัปเดตจาก GitHub |
| `bar.json`, `settings.json`, `check/` | ข้อมูลของเครื่องนี้ (ไม่อัปขึ้น git) |
